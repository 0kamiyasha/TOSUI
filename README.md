**Complete UI layout without the need to sub to a streamer.**

TOSUI is a retail World of Warcraft installer that drops you into a full, raid-ready interface in a few clicks — no Patreon gate, no “watch my stream for the string,” no hunting Wago links across Discord.

## What you get

- **One installer** — `/tui` or `/tos` walks you through setup end to end

## Quick start

1. Install **TOSUI** and **TOSUI_Data** into `Interface/AddOns`
2. Enable both addons (plus EllesmereUI and whatever else you use)
3. In game: `/tui` (or `/tos`)
4. Pick resolutions, run Setup, finish, reload

Built for players who just want a clean UI and to get into the pull.
